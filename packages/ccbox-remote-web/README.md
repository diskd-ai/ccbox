# ccbox-remote-web

Web remote dashboard for [ccbox](../../README.md) -- browse, analyze, and manage coding agent sessions (Codex, Claude, Gemini, OpenCode) from any browser.

## Tech stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```
